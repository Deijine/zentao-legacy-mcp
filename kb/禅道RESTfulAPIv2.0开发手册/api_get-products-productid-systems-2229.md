# 获取产品应用列表

GET/products/:productID/systems

##  获取产品应用列表 

### 请求URL
https://xxx.com/api.php/v2/products/:productID/systems

### 请求头
|  名称  类型  必填  描述
|  token  string  是  访问凭证Token

### 请求参数
|  名称  必填  描述

### 请求响应
|  名称  类型  描述
|  status  string  状态(success 成功 | fail 失败)

### 响应示例

```
{
    "status": "success"
}
```

# 禅道二次开发简介

为了方便用户增加新的功能、修改现有代码或者进行第三方系统集成，禅道提供强大的扩展机制、全面的API接口以及命令行调用三种方式，满足企业用户的特色需求。

扩展机制：可以使用PHP、HTML、CSS或者JS代码来对现有的代码功能进行改动。作为开源软件，禅道用户可以参考系统已有的代码进行改造，更快上手。

API 接口：可以通过HTTP协议访问或者修改禅道的数据，和其他系统进行集成；

 命令行调用：可以通过命令行调用应用内部的方法，可以用来做备份、更新、发信等操作； 

 注意：本文档的内容是针对最新20系列版本的禅道代码。
